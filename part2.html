⚠️ 多重循环 —— 6大易错点（扩充版）

🚨 错误1：内外层循环变量重名

内外循环都用同一个变量i → 冲突！必须用不同的变量名！

🚨 错误2：混淆内外层执行次数

外层m次 × 内层n次 = 总执行m×n次。考试常考！

🚨 错误3：忘记内层结束后要换行

打印多行图形时，内层循环结束后必须printf("\n")换行。

🚨 错误4：内外循环变量混淆（边界条件）

打印三角形时，内层循环条件应该和外层变量i有关（如j<=i），不要写死。

🚨 错误5：交叉嵌套（语法错误）

循环嵌套必须完整嵌套，不能交叉！

🚨 错误6：以为break能跳出所有层

嵌套循环中，break只能跳出它所在的那一层循环！

⚖️ break vs continue —— 对比示例

问题：输出1~10中能被3整除的数

用break实现？

❌ break是"全退"，不适合筛选数据
筛选数据应该用continue！

用continue实现

for(i=1; i<=10; i++)
{
    if(i%3 != 0)
        continue;  // 不能整除？跳过！
    printf("%d ", i);
}

✅ continue是"半退"，适合筛选数据

⚠️ break/continue —— 6大易错点

🚨 错误1：混淆break和continue的作用

break = 全退（跳出整个循环），continue = 半退（跳过本轮）。

🚨 错误2：误以为continue后循环变量不更新

for中遇到continue，表达式3（i++）仍然会执行！

🚨 错误3：嵌套循环中break只跳一层

break只能跳出它所在的那一层循环！

🚨 错误4：continue用在switch里

continue只能用在循环语句中！switch里用break。

🚨 错误5：以为break后循环变量还会更新

遇到break时，循环立即结束！后面的变量更新都不执行了。

🚨 错误6：把break当成continue用

筛选数据时应该用continue，用了break就直接结束循环了！

🏆 综合实例1：素数判断（详细分步讲解）

📌 算法分析

素数：大于1，除了1和它本身不能被其他数整除。

判断思路：
1. 用2到√n之间的数去试除
2. 如果有一个能整除 → 不是素数
3. 如果都不能整除 → 是素数
4. 用tag（标志变量）记录结果

💻 完整代码

#include <math.h>
main()
{
    int num, j, tag=1, m;
    printf("输入一个数：");
    scanf("%d", &num);
    m = sqrt(num);
    for(j=2; j<=m; j++)
    {
        if(num % j == 0)
        {
            tag = 0;
            break;
        }
    }
    if(tag == 1)
        printf("%d是素数", num);
    else
        printf("%d不是素数", num);
}
