代码：外层i从1到3，内层j从1到2，输出i和j的值

外层轮次内层轮次i的值j的值输出内容内层结束后
第1轮(i=1)第1次11i=1,j=1j++→2
第2次12i=1,j=2j++→3，内层结束
第2轮(i=2)第1次21i=2,j=1j++→2
第2次22i=2,j=2j++→3，内层结束
第3轮(i=3)第1次31i=3,j=1j++→2

⚠️ 多重循环 —— 6大易错点（扩充版）

🚨 错误1：内外层循环变量重名
for(i=1; i<=3; i++)
{
    for(i=1; i<=5; i++)  // ← 内外都用i！冲突！
        printf("*");
}
🚨 错误2：混淆内外层执行次数

外层m次 × 内层n次 = 总执行m×n次。考试常考！

🚨 错误3：忘记内层结束后要换行

打印多行图形时，内层循环结束后必须printf("\n")换行。

🚨 错误4：内外循环变量混淆（边界条件）

打印三角形时，内层循环条件应该和外层变量i有关（如j<=i），不要写死。

🚨 错误5：交叉嵌套（语法错误）

循环嵌套必须完整嵌套，不能交叉！外层开了内层没关又关外层，编译错误。

🚨 错误6：以为break能跳出所有层

嵌套循环中，break只能跳出它所在的那一层循环，外层循环还在继续！

⚖️ break vs continue —— 对比示例（同一问题两种解法）

问题：输出1~10中能被3整除的数

用break实现？

// 不适合！break是跳出整个循环
// 不能用来筛选数据
for(i=1; i<=10; i++)
{
    if(i%3 == 0)
        printf("%d ", i);
    // break用在这里就全完了
}

❌ break是"全退"，不适合筛选

用continue实现

for(i=1; i<=10; i++)
{
    if(i%3 != 0)
        continue;  // 不能整除？跳过！
    printf("%d ", i);
    // 只有能整除的才输出
}

✅ continue是"半退"，适合筛选数据

⚠️ break/continue —— 6大易错点（扩充版）

🚨 错误1：混淆break和continue的作用

break = 全退（跳出整个循环），continue = 半退（跳过本轮）。考试必考！

🚨 错误2：误以为continue后循环变量不更新

for中遇到continue，表达式3（i++）仍然会执行！
例：for(i=1;i<=5;i++){ if(i==3) continue; printf("%d",i); }
输出：1 2 4 5（i=3跳过printf，但i++变成4了）

🚨 错误3：嵌套循环中break只跳一层

break只能跳出它所在的那一层循环，外层循环还在继续！

🚨 错误4：continue用在switch里

continue只能用在循环语句中，不能用在switch语句里！switch里用break。

🚨 错误5：以为break后循环变量还会更新

遇到break时，循环立即结束！后面的变量更新、循环体剩余语句都不执行了。

🚨 错误6：把break当成continue用

筛选数据时应该用continue（跳过不符合条件的），用了break就直接结束循环了，结果完全不对。

🏆 综合实例1：素数判断（详细分步讲解）

📌 算法分析

素数：大于1，除了1和它本身不能被其他数整除。

判断思路：
1. 用2到√n之间的数去试除
2. 如果有一个能整除 → 不是素数
3. 如果都不能整除 → 是素数
4. 用tag（标志变量）记录结果

💻 完整代码

#include <math.h>
main()
{
    int num, j, tag=1, m;
    printf("输入一个数：");
    scanf("%d", &num);
    m = sqrt(num);
    for(j=2; j<=m; j++)
    {
        if(num % j == 0)
        {
            tag = 0;
            break;
        }
    }
    if(tag == 1)
        printf("%d是素数", num);
    else
        printf("%d不是素数", num);
}

🏆 综合实例2：百钱百鸡问题

📌 问题描述

公鸡5元一只，母鸡3元一只，小鸡3只一元。
用100元买100只鸡，问公鸡、母鸡、小鸡各买多少只？

💡 分析

设公鸡x只，母鸡y只，小鸡z只
方程1：x + y + z = 100
方程2：5x + 3y + z/3 = 100
用穷举法，双层循环遍历所有可能。

💻 代码实现

main()
{
    int x, y, z;
    for(x=0; x<=20; x++)  // 公鸡最多20只
    {
        for(y=0; y<=33; y++)  // 母鸡最多33只
        {
            z = 100 - x - y;
            if(z%3==0 && 5*x+3*y+z/3==100)
                printf("公鸡=%d 母鸡=%d 小鸡=%d\n", x, y, z);
        }
    }
}
输出4组解：(0,25,75) (4,18,78) (8,11,81) (12,4,84)

💻 课后练习：程序题（10道，附思路）

【1】求1+2+3+...+100的和
思路：循环累加，sum=0，i从1到100，sum+=i。考点：循环基本用法
【2】求1~100的偶数和
思路：for(i=2;i<=100;i+=2) sum+=i。考点：步长为2的循环
【3】求n的阶乘 n!
思路：t=1，i从1到n，t*=i。考点：累乘，初始值为1
【4】统计1~100中能被3整除的数的个数
思路：count=0，循环判断i%3==0则count++。考点：计数器用法
【5】输出100~200之间所有能被7整除的数
思路：for循环从100到200，判断i%7==0则输出。考点：循环+条件判断
【6】输入一个数，判断是否为素数
思路：用2到√n试除，tag标志变量。考点：素数算法+break
【7】打印4行5列星号矩形
思路：双层循环，外层行内层列，内层结束后换行。考点：循环嵌套基本结构
【8】打印4行直角三角形
思路：外层i从1到4，内层j从1到i。考点：内层循环次数随外层变化
【9】打印九九乘法表
思路：双层循环，外层i行，内层j列，输出i*j。考点：嵌套循环+格式化输出
【10】求1!+2!+...+10!的和
思路：外层循环算阶乘，内层循环累加。考点：嵌套循环+累加累乘综合
