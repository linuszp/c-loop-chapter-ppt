🔑 循环结构三要素

任何一个循环都必须包含以下三个要素，缺一不可：

1
循环变量赋初值
循环开始前给控制变量一个初始值
例：i = 1;
2
循环条件判断
每次循环前判断条件是否成立
例：i <= 5
3
循环变量更新
循环体中必须有改变循环变量的语句
例：i = i + 1;
⚠️ 死循环警告：缺少第3要素 → 循环永远无法结束 → 死循环！

4.1 while 循环 —— 当型循环

📝 一般形式

while (表达式)
{
    语句序列;  // 循环体
}

📌 执行特点

  • 先判断，后执行
  • 表达式为真(非0) → 执行循环体
  • 表达式为假(0) → 结束循环
  • 循环体可能执行0次或多次

🔄 执行流程

开始
↓
表达式? (判断)
↓ 真(非0)
语句序列 (循环体)
↑ 回到判断

📖 例4-1：求 1+2+3+4+5 的和

💻 程序代码

#include <stdio.h>
main()
{
    int sum, i;
    sum = 0;     // 累加器清零
    i = 1;       // 循环变量赋初值
    while (i <= 5)
    {
        sum = sum + i;  // 累加
        i = i + 1;     // 循环变量更新
    }
    printf("sum = %d", sum);
}

🔍 执行过程

轮次isumi<=5?
初始10—
第1次21真
第2次33真
第3次46真
第4次510真
第5次615真
第6次判断615假→退出

运行结果：sum = 15

⚠️ while循环 —— 易错点总结

🚨 错误1：忘记循环变量更新 → 死循环
i = 1;
while(i <= 5)
{
    sum = sum + i;
    // 忘了 i = i + 1; → i永远=1 → 死循环！
}
🚨 错误2：累加器未清零
int sum;  // sum是随机值！
// ✅ 正确：sum = 0; 必须在循环前写
🚨 错误3：while后面多加了分号
while(i <= 5);  // ← 分号！循环体变成空语句
{
    sum = sum + i;  // 这行不在循环里！
}

4.2 do...while 循环 —— 直到型循环

📝 一般形式

do
{
    语句序列;  // 循环体
}while(表达式);  // ← 分号不能漏！

📌 执行特点

  • 先执行，后判断
  • 先执行一次循环体，再判断条件
  • 条件为真 → 继续下一轮循环
  • 循环体至少执行一次！

🔄 执行流程

开始
↓
语句序列 ← 先执行！
↓
表达式? (判断)
↑ 真(非0) 假(0)→结束

📖 例4-3：逆序输出一个整数

💻 程序代码

main()
{
    long num;
    int b;
    printf("输入一个整数：");
    scanf("%ld", &num);
    do
    {
        b = num % 10;   // 取个位数
        printf("%d", b);
        num = num / 10; // 去掉个位数
    } while(num);      // num非0继续
}

🔍 执行过程（输入54321）

轮次b(输出)num(剩余)num为0?
初始—54321否
第1轮15432否
第2轮2543否
第3轮354否
第4轮45否
第5轮50是→结束

输出结果：12345

⚠️ do...while循环 —— 易错点

🚨 错误1：while后面丢了分号
do
{
    sum = sum + i;
    i++;
} while(i <= 5)  // ← 少了分号！编译错误
// ✅ 正确：} while(i <= 5);
🚨 错误2：忘记至少执行一次

do...while不管条件是否成立，至少先执行一次循环体。如果num一开始就是0，do...while会先输出一个0。

🚨 错误3：花括号省略问题

即使循环体只有一条语句，do...while的花括号也建议写上，避免语法混乱。

⚖️ while 与 do...while 对比

对比项while循环do...while循环
执行顺序先判断条件，后执行循环体先执行循环体，后判断条件
执行次数0次或多次至少1次
相同点第一次条件就为真时，两种循环结果相同
不同点第一次条件为假时，while一次不执行，do...while执行一次
while版：条件为假 → 一次不执行
do...while版：条件为假 → 已执行一次

✏️ do...while循环 —— 春考选择题（题目）

【第1题】do...while循环中，循环体的执行情况是（ ）
A. 至少执行一次B. 可能执行0次C. 固定执行两次D. 最多执行一次
【第2题】以下程序运行结果是（ ）
int i=5, s=0;
do
{ s += i; i--; }
while(i > 0);
printf("%d", s);
A. 10B. 15C. 死循环D. 0
【第3题】do...while语句结束时，while后面（ ）
A. 不能有分号B. 必须有分号C. 可有可无D. 必须有逗号

✅ do...while循环 —— 选择题答案

第1题：A. 至少执行一次
解析：do...while是先执行后判断，不管条件真假，循环体至少执行一次。这是它和while最大的区别。
第2题：B. 15
解析：5+4+3+2+1=15。i从5开始，每次减1，直到i=0时条件i>0为假退出。
第3题：B. 必须有分号
解析：do...while是一条完整语句，while(表达式)后面必须加分号，否则编译报错。考试常考点！

4.3 for 循环 —— 最灵活的循环

📝 一般形式

for (表达式1; 表达式2; 表达式3)
{
    语句序列;
}
// 表达式1 → 初始化（只执行1次）
// 表达式2 → 循环条件（每次判断）
// 表达式3 → 循环变量更新（每次执行完后）

🔄 执行流程

① 计算表达式1（初始化）
↓
② 计算表达式2（条件判断）
↓ 真
③ 执行循环体语句
↓
④ 计算表达式3（更新变量）
↑ 回到②

📖 例4-4：输入10个整数，求其和

💻 程序代码

#include <stdio.h>
main()
{
    int i, num, sum;
    sum = 0;
    for(i=1; i<=10; i++)
    {
        scanf("%d", &num);
        sum = sum + num;
    }
    printf("和为：%d", sum);
}
💡 for vs while：for把初始化、条件、更新写在一行，更紧凑。循环次数明确时优先用for。

🔍 for循环三要素对应

i=1 → 初始化（表达式1）
i<=10 → 循环条件（表达式2）
i++ → 变量更新（表达式3）
退出循环时：i = 11
（i=10时执行循环体，然后i++变成11，再判断为假退出）

⚠️ for循环 —— 易错点总结

🚨 错误1：误把"小于等于"写成"小于"
for(i=1; i<10; i++)  // ← 应该是 i<=10！
    sum += i;
// 结果只加到9，少了最后一个数！
🚨 错误2：for后面多加了分号
for(i=1; i<=5; i++);  // ← 分号！循环体是空语句
{
    printf("%d", i);  // 这行不在循环里！
}
🚨 错误3：三个表达式都可省略，但分号不能省

for的三个表达式都可以省略，但两个分号必须保留。省略表达式2相当于条件永远为真（死循环）。

A. 只能省略表达式1B. 只能省略表达式2C. 三个表达式都可省略，但分号不能省D. 三个表达式都不能省略

✅ for循环 —— 选择题答案

第1题：B. 10次
解析：i从0到9，共10个值，执行10次。当i=10时条件i<10为假退出。
第2题：B. 6
解析：注意for后面有分号！循环体是空语句。i=1,2,3,4,5都执行了空循环体，然后i++变成6，此时i<=5为假退出。
第3题：C. 三个表达式都可省略，但分号不能省
解析：for的三个表达式都可以省略，但两个分号必须保留。省略表达式2相当于条件永远为真。

💻 for循环 —— 编程练习题

【程序题1】求1~100的偶数和

4.4 多重循环（循环嵌套）

📌 什么是循环嵌套？

一个循环的循环体中又包含另一个完整的循环结构，称为循环嵌套。

三种循环（while、do...while、for）可以相互嵌套，自由组合。

🔑 执行规律：
外层循环执行1次 → 内层循环完整执行n次
外层走一圈，内层跑一圈！

🔄 嵌套执行示意图

for(i=1; i<=3; i++)  // 外层：3次
{
    for(j=1; j<=2; j++) // 内层：2次
    {
        printf("i=%d j=%d\n", i, j);
    }
}
// 总执行次数 = 3 × 2 = 6次
i=1 j=1
i=1 j=2
i=2 j=1
i=2 j=2
i=3 j=1
i=3 j=2

📖 例4-6：打印九九乘法表

💻 程序代码

main()
{
    int i, j;
    for(i=1; i<10; i++)
        printf("%4d", i);
    printf("\n");
    for(i=1; i<10; i++)      // 外层：行
    {
        for(j=1; j<10; j++)  // 内层：列
            printf("%4d", i*j);
        printf("\n");        // 换行
    }
}

📋 输出结果

1 2 3 4 5 6 7 8 9
2 4 6 8 10 12 14 16 18
3 6 9 12 15 18 21 24 27
4 8 12 16 20 24 28 32 36
5 10 15 20 25 30 35 40 45
6 12 18 24 30 36 42 48 54
7 14 21 28 35 42 49 56 63
8 16 24 32 40 48 56 64 72
9 18 27 36 45 54 63 72 81

⚠️ 循环嵌套 —— 易错点

🚨 错误1：内外层循环变量重名
for(i=1; i<=3; i++)
{
    for(i=1; i<=5; i++)  // ← 内外都用i！冲突！
        printf("*");
}
// ✅ 正确：内层用j、k等不同变量名
🚨 错误2：混淆内外层执行次数

外层执行m次，内层执行n次，循环体总执行次数 = m × n。
考试常考：外层3次，内层4次，printf执行多少次？→ 12次！

🚨 错误3：忘记内层结束后要换行

打印多行图形时，内层循环负责打印一行，内层结束后必须printf("\n")换行。

✏️ 多重循环 —— 春考选择题（题目）

【第1题】printf语句执行的次数是（ ）

    for(j=1; j<=3; j++)
        printf("*");
A. 7次B. 12次C. 3次D. 4次
【第2题】关于循环嵌套，下列说法正确的是（ ）
A. 只能for嵌套forB. while不能嵌套forC. 三种循环可以相互嵌套D. 最多只能嵌套两层
【第3题】外层循环执行一次，内层循环（ ）
A. 执行一次B. 执行完整一轮C. 不执行D. 执行两次

✅ 多重循环 —— 选择题答案

第1题：B. 12次
解析：外层4次 × 内层3次 = 12次。i=1时j跑1-3，i=2时j又跑1-3...以此类推。
第2题：C. 三种循环可以相互嵌套
解析：while、do...while、for三种循环可以任意嵌套，没有限制。for里可以套while，while里也可以套for。
第3题：B. 执行完整一轮
解析：外层循环每走一步，内层循环要从头到尾完整执行一遍。外层走一圈，内层跑一圈。

4.5.1 break 语句 —— 跳出整个循环

📌 作用

立即跳出当前整个循环，执行循环后面的语句。

就像跑步比赛中有人突然喊"停！"，所有人立刻停止。

⚠️ 注意事项

  • 只能用在循环语句和switch语句中
  • 嵌套循环中，break只跳出它所在的那一层

🔄 例4-7：体积超100就停止

for(r=1; r<=10; r++)
{
    v = PI * r * r * h;
    if(v > 100.0)
        break;  // 体积超了，跳出循环
    printf("r=%d, v=%.2f\n", r, v);
}
printf("此时 r = %d\n", r);
r=1, v=18.84
r=2, v=75.36
// r=3时 v=169.56>100 → break
此时 r = 3

4.5.2 continue 语句 —— 跳过本次循环

📌 作用

跳过循环体中剩余的语句，直接进入下一轮循环。

就像跑步时某一圈有人说"这圈不算，下一圈重来"，但比赛还在继续。

⚠️ 注意事项

  • 只能用在循环语句中
  • continue之后的循环体语句不执行
  • 循环变量更新（表达式3）仍然会执行

🔄 例4-8：输出能被7整除的数

for(num=50; num<=100; num++)
{
    if(num%7 != 0)
        continue;  // 不能被7整除？跳过！
    printf("%d\n", num);
    // 只有能被7整除的才输出
}
输出：56 63 70 77 84 91 98

⚖️ break 与 continue 对比（春考必考点）

对比项breakcontinue
作用范围整个循环仅本次循环
循环状态彻底结束循环结束本轮，进入下一轮
执行后跳到循环后面的语句跳到循环条件判断
用在switch中可以不可以
🚪 break = 出口
直接走出整个循环房间
⏭️ continue = 跳过
这一圈不跑了，开始下一圈

{

for(i=1; i<=5; i++)

A. 结束整个循环B. 结束本次循环，进入下一次C. 跳出switch语句D. 暂停程序

✅ break/continue —— 选择题答案

第1题：B. 1 2
解析：i=1输出1，i=2输出2，i=3时遇到break直接跳出整个循环！所以3、4、5都不输出了。
第2题：C. 1 2 4 5
解析：i=1输出1，i=2输出2，i=3时遇到continue跳过printf（但i++还是执行了变成4），i=4输出4，i=5输出5。
第3题：B. 结束本次循环，进入下一次
解析：continue只结束本轮循环，跳过后面的语句，直接开始下一轮。注意continue不能用在switch中！

🏆 综合实例：判断素数（例4-9）

📌 什么是素数？

素数（质数）：大于1的自然数，除了1和它本身，不能被其他任何数整除。

例：2, 3, 5, 7, 11, 13... 是素数
4, 6, 8, 9, 10, 12... 不是素数

💡 判断思路

  • 用2 ~ √num 之间的数去试除
  • 有一个能整除 → 不是素数
  • 都不能整除 → 是素数
  • 用tag（标志变量）记录结果

💻 核心代码

int num, j, tag=1, m;
scanf("%d", &num);
m = sqrt(num);  // 除到平方根即可
for(j=2; j<=m; j++)
{
    if(num % j == 0)
    {
        tag = 0;  // 能整除，不是素数
        break;     // 找到了就不用再试
    }
}
if(tag == 1)
    printf("%d是素数", num);
else
    printf("%d不是素数", num);

🎯 核心知识点：
① 三种循环语句：while、do...while、for
② 循环三要素：赋初值、判条件、更改变量
③ do...while至少执行一次，while/for可能执行0次
④ 循环嵌套：外层走1次，内层跑1圈
⑤ break = 跳出整个循环；continue = 跳过本轮
⑥ 典型算法：累加、累乘、计数、素数、九九表
