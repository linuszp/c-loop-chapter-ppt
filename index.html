🔑 循环结构三要素

任何一个循环都必须包含以下三个要素，缺一不可：

1
循环变量赋初值
循环开始前给控制变量一个初始值
例：i = 1;
2
循环条件判断
每次循环前判断条件是否成立
例：i <= 5
3
循环变量更新
循环体中必须有改变循环变量的语句
例：i = i + 1;
⚠️ 死循环警告：缺少第3要素 → 循环永远无法结束 → 死循环！

4.1 while 循环 —— 当型循环

📝 一般形式

while (表达式)
{
    语句序列;  // 循环体
}

📌 执行特点

  • 先判断，后执行
  • 表达式为真(非0) → 执行循环体
  • 表达式为假(0) → 结束循环
  • 循环体可能执行0次或多次

🔄 执行流程

开始
↓
表达式? (判断)
↓ 真(非0)
语句序列 (循环体)
↑ 回到判断

📖 例4-1：求 1+2+3+4+5 的和

💻 程序代码

#include <stdio.h>
main()
{
    int sum, i;
    sum = 0;     // 累加器清零
    i = 1;       // 循环变量赋初值
    while (i <= 5)
    {
        sum = sum + i;  // 累加
        i = i + 1;     // 循环变量更新
    }
    printf("sum = %d", sum);
}

🔍 执行过程

轮次isumi<=5?
初始10—
第1次21真
第2次33真
第3次46真
第4次510真
第5次615真
第6次判断615假→退出

运行结果：sum = 15

⚠️ while循环 —— 易错点总结

🚨 错误1：忘记循环变量更新 → 死循环
i = 1;
while(i <= 5)
{
    sum = sum + i;
    // 忘了 i = i + 1; → i永远=1 → 死循环！
}
🚨 错误2：累加器未清零
int sum;  // sum是随机值！
// ✅ 正确：sum = 0; 必须在循环前写
🚨 错误3：while后面多加了分号
while(i <= 5);  // ← 分号！循环体变成空语句
{
    sum = sum + i;  // 这行不在循环里！
}

✏️ while循环 —— 春考选择题（题目）

【第1题】while循环中的循环体（ ）
A. 至少执行一次B. 可能执行0次C. 固定执行n次D. 最多执行一次
【第2题】以下程序运行结果是（ ）
int i=1, s=0;
while(i <= 3)
{ s += i; i++; }
printf("%d", s);
A. 3B. 6C. 死循环D. 0
【第3题】while(i!=0)循环结束的条件是（ ）
A. i等于0B. i不等于0C. i大于0D. i小于0

✅ while循环 —— 选择题答案

第1题：B. 可能执行0次
解析：while是先判断后执行，如果第一次条件就为假，循环体一次都不执行。
第2题：B. 6
解析：1+2+3=6。i=1时s=1，i=2时s=3，i=3时s=6，i=4时条件为假退出。
第3题：A. i等于0
解析：while(i!=0)表示i不等于0时继续循环，所以i=0时条件为假，循环结束。
