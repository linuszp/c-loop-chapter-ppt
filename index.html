🔑 循环结构三要素

任何一个循环都必须包含以下三个要素，缺一不可：

1
循环变量赋初值
循环开始前给控制变量一个初始值
例：i = 1;
2
循环条件判断
每次循环前判断条件是否成立
例：i <= 5
3
循环变量更新
循环体中必须有改变循环变量的语句
例：i = i + 1;
⚠️ 死循环警告：缺少第3要素 → 循环永远无法结束 → 死循环！

4.1 while 循环 —— 当型循环

📝 一般形式

while (表达式)
{
    语句序列;  // 循环体
}

📌 执行特点

  • 先判断，后执行
  • 表达式为真(非0) → 执行循环体
  • 表达式为假(0) → 结束循环
  • 循环体可能执行0次或多次

🔄 执行流程图

开始
↓
表达式? (判断)
↓ 真(非0)
语句序列 (循环体)
↑ 回到表达式判断
假(0) → 结束循环

📖 例4-1：求 1+2+3+4+5 的和

💻 程序代码

#include <stdio.h>
main()
{
    int sum, i;
    sum = 0;     // 累加器清零
    i = 1;       // 循环变量赋初值
    while (i <= 5)
    {
        sum = sum + i;  // 累加
        i = i + 1;     // 循环变量更新
    }
    printf("sum = %d", sum);
}

🔍 执行过程跟踪表

轮次isumi<=5?
初始10—
第1次21真
第2次33真
第3次46真
第4次510真
第5次615真
第6次判断615假→退出

运行结果：sum = 15

⚠️ while循环 —— 5大易错点

🚨 错误1：忘记循环变量更新 → 死循环
i = 1;
while(i <= 5)
{
    sum = sum + i;
    // 忘了 i = i + 1; → i永远=1 → 死循环！
}
🚨 错误2：累加器未清零
int sum;  // sum是随机垃圾值！
while(i <= 5) { sum += i; i++; }
// ✅ 正确：sum = 0; 必须在循环前写
🚨 错误3：while后面多加了分号
while(i <= 5);  // ← 分号！循环体变成空语句
{
    sum = sum + i;  // 这行根本不在循环里！
}
🚨 错误4：循环条件写反（<写成>）

想写i<=5，写成i>=5 → 第一次判断就为假，循环一次不执行。考试常考！

🚨 错误5：循环体忘记加花括号

while后面默认只管第一条语句！如果循环体有多条语句，必须用{}括起来。

✅ while循环 —— 选择题答案解析

第1题：B. 可能执行0次
解析：while是先判断后执行，如果第一次条件就为假，循环体一次都不执行。
第2题：B. 6
解析：1+2+3=6。i=1时s=1，i=2时s=3，i=3时s=6，i=4时条件为假退出。
第3题：A. i等于0
解析：while(i!=0)表示i不等于0时继续循环，所以i=0时条件为假，循环结束。
第4题：A. 30
解析：10+8+6+4+2=30。i从10开始，每次减2，直到i=0时条件i>0为假退出。
第5题：B. 非0
解析：C语言中，表达式值为非0即为真，循环继续执行；为0即为假，循环结束。

4.2 do...while 循环 —— 直到型循环

📝 一般形式

do
{
    语句序列;  // 循环体
}while(表达式);  // ← 分号不能漏！

📌 执行特点

  • 先执行，后判断
  • 先执行一次循环体，再判断条件
  • 条件为真 → 继续下一轮循环
  • 循环体至少执行一次！

🔄 执行流程图

开始
↓
语句序列 ← 先执行！
↓
表达式? (判断)
↑ 真(非0) 假(0)→结束循环

📖 例4-3：逆序输出一个整数

💻 程序代码

main()
{
    long num;
    int b;
    printf("输入一个整数：");
    scanf("%ld", &num);
    do
    {
        b = num % 10;   // 取个位数
        printf("%d", b);
        num = num / 10; // 去掉个位数
    } while(num);      // num非0继续
}

🔍 执行过程（输入54321）

轮次b(输出)num(剩余)num为0?
初始—54321否
第1轮15432否
第2轮2543否
第3轮354否
第4轮45否
第5轮50是→结束

输出结果：12345

⚖️ while 与 do...while 对比

对比项while循环do...while循环
执行顺序先判断条件，后执行循环体先执行循环体，后判断条件
执行次数0次或多次至少1次
相同点第一次条件就为真时，两种循环结果完全相同
不同点第一次条件为假时，while一次不执行，do...while会执行一次
分号while()后无分号while()后必须有分号
while版：条件为假 → 一次不执行
do...while版：条件为假 → 已执行一次

⚠️ do...while循环 —— 5大易错点

🚨 错误1：while后面丢了分号
do
{
    sum = sum + i;
    i++;
} while(i <= 5)  // ← 少了分号！编译错误
// ✅ 正确：} while(i <= 5);
🚨 错误2：忘记至少执行一次

do...while不管条件是否成立，至少先执行一次循环体。如果num一开始就是0，do...while会先输出一个0。

🚨 错误3：花括号省略问题

即使循环体只有一条语句，do...while的花括号也建议写上，否则容易语法混乱。

🚨 错误4：把do...while当成while用

有些同学写do...while时忘了do，或者把do和while的位置搞反。记住：do在前面，while在后面！

🚨 错误5：循环变量更新位置错误

循环变量更新必须写在循环体内部，不能写在while()的括号里。否则会导致死循环。

✅ do...while循环 —— 选择题答案

第1题：A. 至少执行一次
解析：do...while是先执行后判断，不管条件真假，循环体至少执行一次。
第2题：B. 15
解析：5+4+3+2+1=15。i从5开始，每次减1，直到i=0时条件i>0为假退出。
第3题：B. 必须有分号
解析：do...while是一条完整语句，while(表达式)后面必须加分号，否则编译报错。
第4题：B. 1
解析：先执行一次循环体：s=1，i=2。然后判断i<=1？2<=1为假，退出。所以s=1。
第5题：C. 先执行后判断
解析：do...while的特点就是先执行循环体，再判断条件。while是先判断后执行。

4.3 for 循环 —— 最灵活的循环

📝 一般形式

for (表达式1; 表达式2; 表达式3)
{
    语句序列;
}
// 表达式1 → 初始化（只执行1次）
// 表达式2 → 循环条件（每次判断）
// 表达式3 → 循环变量更新（每次执行完后）

🔄 执行流程图

① 计算表达式1（初始化）
↓
② 计算表达式2（条件判断）
↓ 真
③ 执行循环体语句
↓
④ 计算表达式3（更新变量）
↑ 回到②

📖 例4-4：输入10个整数，求其和

💻 程序代码

#include <stdio.h>
main()
{
    int i, num, sum;
    sum = 0;
    for(i=1; i<=10; i++)
    {
        scanf("%d", &num);
        sum = sum + num;
    }
    printf("和为：%d", sum);
}
💡 for vs while：for把初始化、条件、更新写在一行，更紧凑。循环次数明确时优先用for。

🔍 for循环三要素对应

i=1 → 初始化（表达式1）
i<=10 → 循环条件（表达式2）
i++ → 变量更新（表达式3）
退出循环时：i = 11
（i=10时执行循环体，然后i++变成11，再判断为假退出）

⚠️ for循环 —— 5大易错点

🚨 错误1：误把"小于等于"写成"小于"
for(i=1; i<10; i++)  // ← 应该是 i<=10！
    sum += i;
// 结果只加到9，少了最后一个数！
🚨 错误2：for后面多加了分号
for(i=1; i<=5; i++);  // ← 分号！循环体是空语句
{
    printf("%d", i);  // 这行不在循环里！
}
🚨 错误3：三个表达式都可省略，但分号不能省

for的三个表达式都可以省略，但两个分号必须保留。省略表达式2相当于条件永远为真（死循环）。

🚨 错误4：误以为表达式3在循环体之前执行

执行顺序：表达式1 → 判断表达式2 → 执行循环体 → 表达式3 → 再判断...
表达式3是在循环体之后执行的！

🚨 错误5：循环变量在循环体内再初始化

表达式1只在循环开始时执行一次！不要把初始化写在循环体内部，否则每次循环都会重置。

✅ for循环 —— 选择题答案解析

第1题：B. 10次
解析：i从0到9，共10个值，执行10次。当i=10时条件i<10为假退出。
第2题：B. 6
解析：注意for后面有分号！循环体是空语句。i=1,2,3,4,5都执行了空循环体，然后i++变成6。
第3题：C. 三个表达式都可省略，但分号不能省
解析：for的三个表达式都可以省略，但两个分号必须保留。省略表达式2相当于条件永远为真。
第4题：A. 30
解析：10+8+6+4+2=30。i从10开始，每次减2，直到i=0时条件i>=1为假退出。
第5题：B. 只执行一次
解析：表达式1是初始化语句，只在循环开始时执行一次。表达式2和表达式3才是每次循环都执行的。
